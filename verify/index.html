With a standard tool

  • On a Mac or Linux:shasum -a 256 entry.json
  • On Windows:certutil -hashfile entry.json SHA256
  • Chain step on a Mac or Linux:printf '%s' '{previous chain fingerprint}:{entry fingerprint}' | shasum -a 256

Timestamp proofs

Each entry has a Bitcoin timestamp. Its proof is entry.json.ots. OpenTimestamps is an open, independent timestamping standard. Check a proof against the exact entry file with its standard tool. This page does not check proofs because that requires a network connection.

Check without us

You don’t need this page. The rules are short:

  1. Text is UTF-8, with Unicode normalized to NFC.

  2. Keys are sorted, with no spaces or line breaks between tokens.

  3. Sealed text holds no decimal numbers; decimals are written as text.

  4. A fingerprint is the SHA-256 of those bytes, written as 64 lowercase hex characters.

  5. Each entry file is published in exactly this form, so the file’s SHA-256 is the entry’s fingerprint.

  6. A chain fingerprint is the SHA-256 of the previous chain fingerprint, a colon, and the entry’s fingerprint. The first entry starts from sixty-four zeros.

  7. Every sealed item carries a random salt, so a short value can’t be guessed from its fingerprint.

A matching fingerprint checks agreement, not accuracy.
